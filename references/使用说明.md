# 使用说明

```
====================  PBL 大报告排版工具链  ====================

一、单个稿件 → LaTeX
    python scripts\docx2tex.py 我的稿件.docx
    python scripts\docx2tex.py 我的稿件.docx -o 我的稿件.tex --upcite
    xelatex 我的稿件.tex

    可选参数：
      -o           输出 .tex 文件名（默认同名）
      --margins    覆盖页边距：上,下,左,右（cm），默认读 Word 里的节边距
      --upcite     正文里的 [1]、[2-3] 转成 \upcite{...}（配合 gbt7714 宏包）

二、多人稿件合并 → 四章式大报告（主流程）
    python scripts\chapters_docx2tex.py 计划.json -o 大报告.tex --compile
    python scripts\chapters_docx2tex.py 提交目录 -o 大报告.tex --auto --compile

    计划 JSON（章顺序：案例回顾、重大问题、次要问题、机制图）：
      {
        "title": "内分泌系统 / PBL 大报告",
        "author": "第 × 组", "date": "2026 年 10 月",
        "chapters": [
          {"title": "案例回顾", "files": ["提交/01_病例.docx"]},
          {"title": "重大问题", "files": ["提交/02_机制.docx"]},
          {"title": "次要问题", "files": ["提交/04_鉴别.docx"]},
          {"title": "机制图", "figures": [{"path": "pics/mech1.png", "caption": "三条链全景"}]}
        ]
      }

    可选参数：
      -o            输出 .tex（输出目录同时放 figures/、分章清单.txt）
      --auto        不给计划文件时，按题目关键词自动分章（结果务必人工复核）
      --compile     生成后自动调 xelatex 编译两遍
      --title/--author/--date   覆盖计划里的封面信息

    输出：
      大报告.tex / 大报告.pdf
      figures/            所有图片
      分章清单.txt        每份稿件落在哪一章、一级标题是什么、文献去重结果

二·五、封面（照 23 级 Case 报告样式）
    计划 JSON 里加 "cover"：
      {"line1": "2023级11组PBL学习", "line2": "学习报告",
       "case": "Case 1：难缠的脖子痛", "tutor": "马凯歌",
       "chair": "朱俊铭", "secretary": "郭育恒",
       "members": ["叶瑞林", "张欣仪", ...], "logo": "pics/logo.png"}
    命令行也可以： --cover-line1 "2023级11组PBL学习" --case "Case 1：难缠的脖子痛"
                   --tutor 马凯歌 --chair 朱俊铭 --secretary 郭育恒 --members "甲 乙 丙"
    不给 cover 就退回默认的 \maketitle 标题页。

三、结构（v2）
    第二章  重大问题                       ← 章：居中 / 三号 / 微软雅黑 / 加粗
      1.  结合案例分析泌乳素分泌的调节因素   ← 每份稿件 = 章内一个一级标题
          1.1  病例特点                     ← 稿件里的 1 级标题
              1.1.1  实验室指标             ← 稿件里的 2 级标题
          1.2  小结
      2.  下一个人的题目
    · 一级标题取：稿件题目行（跳过“姓名+学号”）→ 第一个标题 → 文件名；
    · 编号每章从 1. 重新开始；三级封顶，更深层级降为加粗小标题 / (1)(2)(3)；
    · 图/表编号全文连续（图1. 表1.，数字与汉字之间不留空格）。

四、识别规则
    标题     样式 Heading 1-3 / 标题 1-3  →  大纲级别 0-8（9 视为正文）
             →  文本形如 “1.” “1.1.” “1.2核心…” 兜底
    列表     有效 numId（≠0）或 “(1)” 开头；连续“标签：内容”段落自动合成有序列表
    图片     段落里的嵌入图片 → figures/ + figure 环境；紧跟的“图x. ……”作为 \caption
    表格     Word 表格 → booktabs 三线表；宽度三档自适应（自然宽度 / tabularx 折行 /
             \resizebox 缩放），保证不超出正文宽度；合并单元格 → \multicolumn
    文献     “参考文献”标题之后、以 [n] 开头的段落 → thebibliography；
             正文 [n] 直接排成上标编号（不用 \cite，只编译一遍也不会出现 [?,?,?]）；
             多人合并时按内容去重并重编号

五、桌面版（给不会用命令行的同学）
    app/ 里是 tkinter 图形界面：① 单份转换 ② 合并四章 ③ 环境检测。
    打包： cd app && .\build.ps1   （出 onefile 单文件版 + onedir 免安装文件夹版）
    分发优先给免安装文件夹版：单文件版启动要先往 %TEMP% 解包，受限电脑会失败。

六、环境要求
    python-docx    pip install python-docx（桌面版已内置，不用装）
    xelatex        MiKTeX / TeX Live（没有也能生成 .tex）
    中文字体       Windows 字体集（宋体/黑体/微软雅黑），宏包 ctex、geometry、booktabs、
                   array、tabularx、enumitem、caption、natbib
```
