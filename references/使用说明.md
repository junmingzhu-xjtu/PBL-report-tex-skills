# 使用说明

```
====================  大报告排版工具链  ====================

一、单个稿件 → LaTeX
    python tools\docx2tex.py 我的稿件.docx
    python tools\docx2tex.py 我的稿件.docx -o 我的稿件.tex --upcite
    xelatex 我的稿件.tex

    可选参数：
      -o           输出 .tex 文件名（默认同名）
      --margins    覆盖页边距：上,下,左,右（cm），默认读 Word 里的节边距
      --upcite     正文里的 [1]、[2-3] 转成 \upcite{...}（配合 gbt7714 宏包）

二、多人稿件合并 → 一份 LaTeX 大报告
    python tools\merge_docx2tex.py 提交目录 -o 大报告.tex --strip-lead --compile
    （也可以直接列文件： python tools\merge_docx2tex.py a.docx b.docx c.docx）

    可选参数：
      -o            输出 .tex
      --margins     上,下,左,右 cm（默认 2.54,2.54,1.91,1.91）
      --compile     生成后自动调 xelatex 编译 PDF（跑两遍，目录/引用才准）
      --strip-lead  丢掉每个文件第一个标题之前的“个人标题/作者/日期”段落
      --no-toc      不生成目录（默认生成）
      --upcite      正文引用转 \upcite{}

    输出：
      大报告.tex
      figures/            所有图片（按“作者_序号”重命名，不会重名）
      合并清单.txt        每个文件识别到的标题/图/表/文献数 + 去重后的文献表
      大报告.pdf          （加了 --compile 才有）

三、识别规则
    标题     样式 Heading 1-3 / 标题 1-3  →  大纲级别 0-2（9 视为正文）
             →  文本形如 “1.” “1.1.” “1.1.1.” 兜底
             三级封顶；更深层级自动降为 (1)(2)(3) 有序列表
    正文     其余段落；首行缩进 2 字符、1.5 倍行距
    图片     段落里的嵌入图片 → figures/ + figure 环境；紧跟的“图x. ……”作为 \caption
    表格     Word 表格 → booktabs 三线表；表题在表上方/下方都能配对
    文献     “参考文献”标题之后、以 [n] 开头的段落 → thebibliography
             多人合并时按内容去重，正文 [n] 自动重编号到全局序号

四、合并时的编号策略
    · 文件里有 1 个或多个一级标题  → 各自成为合并文档的一级节（1. 2. 3. …），
      其下的 1.1 / 1.1.1 保持不变，全文连续编号
    · 文件里没有任何一级标题（整篇从二级起） → 自动补一节“提交人：文件名”，
      其余标题顺延（二级→三级），超过三级的降为加粗小标题

五、环境要求
    python-docx    pip install python-docx
    xelatex        MiKTeX / TeX Live（本机已装 MiKTeX，路径 …\miktex\bin\x64）
    中文字体       Windows 字体集（宋体/黑体），宏包 ctex、geometry、booktabs、
                   enumitem、caption、natbib（TeX Live/MiKTeX 一般自带）
```
